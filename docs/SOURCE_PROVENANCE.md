## Scientific reproducibility safeguards

- `src/climatology.py` checks grid alignment and zero-export-mask consistency across **54** original 2002–2019 NDVI files. It writes a SHA256 inventory and baseline QA report. Fixed zero mask is explicitly handled, not interpreted as genuine absence of vegetation.
- `src/pipeline.py` independently rebuilds 2021 mortality percentages, repairs invalid province geometry, rejects orphan joins and duplicates, weights longitude–latitude raster cell means approximately by `cos(latitude)`, and reports valid SMAP coverage. Standard zonal unweighted data could bias region comparisons.
- `src/fldas.py` checks raster band `long_name` and `units` for each FLDAS input before calculating monthly flux anomalies.
- Each source product and native output scale is interpreted separately. Values from MODIS MOD13C2 and GEE MOD09GA_NDVI are *not* combined.
- Use `python run_all.py`, then `python -m unittest discover -s tests -v` to rerun the archived input analysis and acceptance tests. The six `notebooks/` files and one `ruralidad/` notebook also contain executed, saved original-data outputs.

## Important limits

These are historical 2022 fellowship observations and a reconstructed pipeline, not claims of modern product revision. The original NASA/JPL preliminary presentations contain additional GLDAS cold-event and ECOSTRESS LST/ESI figures for which an end-to-end validated reconstruction is **not** included. Archived MODIS 18-year baseline TIFFs are materialized and reproducible from the 54 privately stored historical source files; those 54 files are not within this lean public repository. ECOSTRESS samples in 2019 and 2020 have different geographic footprints. SMAP missing-data masks are material in some dry provinces. Interpret cross-provincial correlations as exploratory and non-causal.
