# Ruralidad 2026: validation evidence and audit notebook

This is a **separate 2026 geospatial research project** developed by Aster Volta in collaboration with Dr. Francisco de Aguinaga Padilla. Its book chapter is **in preparation**. It has not been accepted or published.

Open and execute `Ruralidad_H1_REAL_RESEARCH_AUDIT.ipynb` **with the working directory set to this `ruralidad/` folder**. It reads two genuine preserved research files from `data/`, calculates auditable aggregate estimates, and writes outputs into `results/`. It is neither a dummy-data exercise nor a rerun of the complete original Landsat/MapBiomas/INEGI multi-stage pipeline. In this portfolio it is an example of transparent quantitative auditing and scientific validation.

Do not combine this research directly with Mongolia climate data: the projects investigate different places and questions.
